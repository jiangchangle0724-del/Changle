# 任务卡 ho-C13 · 太空站的六关

**负责**：Codex　**审查**：Claude Code　**分支**：`codex/ho-c13-space-levels`　**前提**：太空站的机关和画面（A10，`claude/ho-a10-space` 那个 PR）已合并，先把 main 合进分支。和 C10（后厨）、C11（雪山）、C12（老宅）文件不重叠，可以先后做，也可以同时做。

## 为什么

Steve 11-13 定的第三轮：四个新场景，第四个是太空站。机关 A10 已经做好：**失重区**（`zerog` 里没有重力，人和物件飘着，抓着扶手一推就飘过去，没抓东西时摇杆能轻轻喷气；飘出失重区重力马上回来，底下没地板就掉下去）、**拉杆**（`levers`，有人抓着才算拉下去，开门；门写 `all` 就得几根拉杆一起拉着才开，几根隔得远，得几个人一起拉），要命的东西是撕开的铝板碎片、推进器的喷口、激光栅栏，掉下去是飘出舱外。这张卡做太空站的六关，放进大厅：简单、中等、困难各两关，单人和多人都玩。

## 任务

1. **六关**：`levels/space-43.json` … `space-48.json`，`"world": "space"`，写 `"tier"`：43、44 是 `0`（简单），45、46 是 `1`（中等），47、48 是 `2`（困难）。名字中英文都要有，自己起，和太空站有关（气闸舱、对接口、太阳能板、观景舱、货舱、主控室……）。`teaches` 是 `float`（失重）、`lever`（一起拉杆）、`combine`，困难那两关也可以是 `spike`、`hot`、`zap`、`mover`、`spinner`、`gauntlet`；48 号是 `combine` 或 `gauntlet`。「这关教」的中英文已经在 `src/levels.ts`。
2. **大小、出生点、检查点**：和闯关一样（横着走的宽 2400 到 3600；攀爬关高 1400 到 2200、至少往上一屏；每屏一个检查点；每段 15 到 60 秒；终点在最后；4 个人都有落脚）。`par.seconds` 简单、中等 60 到 180，困难 60 到 240。
3. **失重区至少 4 关**：`zerog` 是几个矩形（每块至少 200 × 200，最多 6 块）。失重区里放扶手（`kind: "peg"` 的小台子，画出来是金属把杆）、墙、会动的台子，让人抓着推着飘过去；底下可以不放地板（飘出去就掉下去，这就是危险），也可以做成往上飘的竖井（攀爬关）。失重区要有用：要么跨过一段没地板的地方，要么飘上够不着的高处。想清楚没抓东西时喷气多慢（170 px/s 封顶），别把路做成只能一点点喷过去。
4. **拉杆至少 3 关**：`levers` 写 `{ x, y, opens }`，把手不压在台子里。**几根拉杆一起开的门（门写 `all`，两根以上拉杆两两隔开 300 px 以上）至少 2 关**，放在困难那一档（或者多人才有的布局里）：简单、中等的关要一个人过得去，只用一根拉杆开的门，门的 `hold` 写长一点（3 秒左右），拉一下松手跑过去来得及。
5. **两样都有至少 2 关**；碎片、喷口、激光各至少 2 关（`hazards` 的 `spike`、`hot`、`zap`；太空站里画出来就是撕开的铝板碎片、推进器喷口、激光栅栏）。激光栅栏可以竖着、横着放在失重区里，飘的时候得绕开。
6. **难度分得开**：简单的一两样机关、要命的东西少、失重区小、没地板的地方窄；中等两三样；困难照难关的规矩（要命的东西至少 4 处、每屏都有，至少一个动台或转杆，两段靠大家，录好的每个手柄单独跑都过不去）。
7. **回放**：每关一份 4 个人的回放 `levels/replays/<id>.json`；按人数摆的关每种摆法一份（`.p<人数>.json`）。**简单、中等的四关另要一份 1 个人的回放** `levels/replays/<id>.p1.json`：单人模式也玩这些关。每份回放：到顶，用时在 `par.seconds` 的 0.5 到 2 倍（1 个人的那份只要不超过 2 倍），检查点按顺序，每块失重区都有人飘过 1 秒，每根拉杆都有人拉过。60 Hz，seq 从 0 递增，没有传送、初始速度、改物理、改复活。所有人一起不动不超过 3 秒。
8. **红包**：每关 3 个，`npm run envelopes` 从四人回放里挑（失重区里的红包要飘过去拿）。
9. **六关各是各的**：台子上沿按 40 px 一格比，和别的任何一关重合不超过 60%，开头那一屏和别的太空站关不超过 85%。不能六关一个套路。
10. **预算**：会动的东西（绳子的节、跷跷板、箱子、动台、转杆、门、缆车的椅子、钥匙、灯笼每个一件）≤ 40，平台 ≤ 60，要命的东西 ≤ 40。
11. **截图和文档**：六张全关截图到 `docs/levels/<id>.png`（1280 × 720，`npm run levels -- --screenshots`）；`docs/levels/README.md` 加太空站一节：每关的布局（名字、tier、teaches、长 × 高、检查点、par、失重区、拉杆和门在哪、怎么过）和结果表。
