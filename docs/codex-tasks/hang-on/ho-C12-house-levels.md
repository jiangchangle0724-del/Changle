## 为什么

Steve 11-13 定的第三轮：四个新场景，第三个是老宅找钥匙。机关 A10 已经做好：**钥匙**（一个能抓、能拽、能丢的小物件，碰到它那扇锁着的门，门就开了、一直开着）、**黑屋子**（`dark` 里看不清，只有每个人身上一圈、墙上的灯、手提的灯笼、亮了的检查点照得到的地方看得见；墙上灭着的灯碰一下就点着），要命的东西是一地碎瓷片、铜炭盆、漏电的老电线，掉下去是荷花池。这张卡做老宅的六关，放进大厅：简单、中等、困难各两关，单人和多人都玩。

## 任务

1. **六关**：`levels/house-37.json` … `house-42.json`，`"world": "house"`，写 `"tier"`：37、38 是 `0`（简单），39、40 是 `1`（中等），41、42 是 `2`（困难）。名字中英文都要有，自己起，和老宅有关（库房、阁楼、天井、祠堂、月亮门、灶间……）。`teaches` 是 `key`（找钥匙开门）、`dark`（黑屋子）、`combine`，困难那两关也可以是 `spike`、`hot`、`zap`、`mover`、`spinner`、`gauntlet`；42 号是 `combine` 或 `gauntlet`。「这关教」的中英文已经在 `src/levels.ts`。
2. **大小、出生点、检查点**：和闯关一样（横着走的宽 2400 到 3600；攀爬关高 1400 到 2200、至少往上一屏；每屏一个检查点；每段 15 到 60 秒；终点在最后；4 个人都有落脚）。`par.seconds` 简单、中等 60 到 180，困难 60 到 240。
3. **钥匙至少 4 关**：`keys` 写 `{ x, y, opens }`，`opens` 是一扇门（`gates` 里的 `id`），这扇门只由钥匙开（不连踏板），一扇门一把钥匙。钥匙放在一块一直在的台子上（中心比台面高 7 px），离要命的东西够远、不压在复活的人身上。门关着的时候长的那一头两边都贴着台子（或关卡边），真挡路，翻不过去（门写 `"grab": false`，或者门顶贴着抓不住的梁）。钥匙要藏一藏：在高柜子顶上、在黑屋子里、在要绕一段路的地方，让人先找、再一只手拿着它走（或者丢上去再爬）到门口。一关可以两三把钥匙开两三扇门（钥匙在上一扇门后面，一串）。
4. **黑屋子至少 3 关**：`dark` 是几个矩形（最多 8 个），连地板一起框进去。每间黑屋子里至少一盏墙灯（`lamps`），或者关里有灯笼（`lanterns`）。墙灯写 `{ x, y, r?, off? }`：`off: true` 是一开始灭着、碰一下就点着（**至少 2 关有要点的灯**，点灯要在路上，主回放里每盏灭着的灯都得点着）。**灯笼至少 2 关**（`{ x, y }`，中心比台面高 20 px，一关最多 2 个）：黑屋子里有了灯笼大家提着走才看得清。黑屋子里也要能玩：要命的东西会自己发光，但台子边、窟窿要靠灯看，别把路做成只能瞎撞。
5. **两样都有至少 2 关**；碎瓷片、炭盆、老电线各至少 2 关（`hazards` 的 `spike`、`hot`、`zap`；老宅里画出来就是碎瓷片、铜炭盆、老电线）。
6. **难度分得开**：简单的一两样机关、要命的东西少、黑屋子小、钥匙好找；中等两三样；困难照难关的规矩（要命的东西至少 4 处、每屏都有，至少一个动台或转杆，两段靠大家，录好的每个手柄单独跑都过不去）。
7. **回放**：每关一份 4 个人的回放 `levels/replays/<id>.json`；按人数摆的关每种摆法一份（`.p<人数>.json`）。**简单、中等的四关另要一份 1 个人的回放** `levels/replays/<id>.p1.json`：单人模式也玩这些关（一个人拿着钥匙也得走得到门口）。每份回放：到顶，用时在 `par.seconds` 的 0.5 到 2 倍（1 个人的那份只要不超过 2 倍），检查点按顺序，每把钥匙都开了它的门（每份回放都要），主回放里每盏灭着的灯都点着了。60 Hz，seq 从 0 递增，没有传送、初始速度、改物理、改复活。所有人一起不动不超过 3 秒。
8. **红包**：每关 3 个，`npm run envelopes` 从四人回放里挑（黑屋子里的红包看不见，正好让人摸黑找）。
9. **六关各是各的**：台子上沿按 40 px 一格比，和别的任何一关重合不超过 60%，开头那一屏和别的老宅关不超过 85%。不能六关一个套路。
10. **预算**：会动的东西（绳子的节、跷跷板、箱子、动台、转杆、门、缆车的椅子、钥匙、灯笼每个一件）≤ 40，平台 ≤ 60，要命的东西 ≤ 40，墙灯 ≤ 24。
11. **截图和文档**：六张全关截图到 `docs/levels/<id>.png`（1280 × 720，`npm run levels -- --screenshots`）；`docs/levels/README.md` 加老宅一节：每关的布局（名字、tier、teaches、长 × 高、检查点、par、钥匙、门、黑屋子、灯在哪、怎么过）和结果表。
