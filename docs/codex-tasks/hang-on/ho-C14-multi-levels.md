**负责**：Codex　**审查**：Claude Code　**分支**：`codex/ho-c14-multi-levels`　**前提**：单人多人和难度（#496）、踩板门（`claude/ho-gates` 那个 PR）已合并，先把 main 合进分支。C9（大团队）可以先做完再做这张：这张卡只动 `levels/multi/`、`docs/levels/multi/`、验收器和探路里多人那一段，不碰 C9 的文件。

## 为什么

Steve 11-13：「游戏进去之后可选择单人模式和多人模式，然后选择简 中 难，多人模式的场景需要有团队配合才能通关。」
大厅已经是这样了：先选单人还是多人，再选简单、中等、困难（`src/sides.ts`，`CONTRACTS.md`「单人、多人和难度」）。可是多人现在用的是和单人一样的 24 关，`npm run probe` 量过：一个人乱按几乎每一段都过得去。这张卡做多人自己的关：一个人怎么都过不去，两个人配合就过得去。关一放进 `levels/multi/`，多人的「一起闯关」这一档就换成它们（`src/levels.ts` 的 `levelsFor` 已经接好），单人和比谁先不受影响。

## 任务

1. **9 关**：`levels/multi/multi-01.json` … `multi-09.json`，每关写 `"tier"`：01 到 03 是 `0`（简单），04 到 06 是 `1`（中等），07 到 09 是 `2`（困难）。每一档两个世界都要有（`"world": "table"` 或 `"van"`）。名字中英文都要有，自己起。`teaches` 从 `chain`（连成一串）、`throw`（丢队友）、`boost`（踩着队友上去）、`hold`（一个按着踏板，一个过门）、`counterweight`（一起压）、`relay`（一个个递上去）、`combine` 里挑，每一档最后一关是 `combine`；「这关教」的中英文已经在 `src/levels.ts` 里。
2. **大小、出生点、检查点**：和闯关一样（横着走的宽 2400 到 3600；攀爬关高 1400 到 2200、至少往上一屏；每屏一个检查点；每段 15 到 60 秒；终点在最后）。**4 个人**都要有落脚：出生点 `spawn.x + 44 × 人`、每个检查点 `cp.x + 30 × 人`（人 = 0 到 3）脚下 80 px 内有不会塌的台子。
3. **一个人过不去**：简单的关至少一段，中等、困难的关至少两段（而且不能只有第一段）一个人过不去：`npm run probe` 从这段的起点 1 个人乱按 200 次，一次都到不了下一个检查点。一个人能干什么（量过的）：任何能抓的墙都爬得上去；抓得到平地上方 250 px 的横杆；扑得过 400 px 宽的坑（扑到对面墙上再爬）。所以要配合的地方得让一个人没办法：墙抓不住（`"grab": false`）又比一个人够得着的高、坑宽到扑不过去对面也没墙、门要有人一直按着踏板才开（一个人按着够不着门、跑过去门已经关了）。
4. **两个人就过得去，而且真配合**：每关 2、3、4 个人各一份回放（`levels/multi/replays/<id>.p2.json`、`.p3.json`、`.p4.json`，格式和闯关一样：60 Hz，seq 从 0 递增，没有传送、初始速度、改物理、改复活）。每份都到顶，用时在 `par.seconds` 的 0.5 到 2 倍，检查点按顺序，摔死不超过 `deathsPerPlayer × 人数`。上面第 3 条那些一个人过不去的段，回放里真的靠配合：两个人以上连成串挂着至少 0.25 秒、一个人站在另一个人身上（或被推上去）、把队友丢过去（松手时队友往右上飞，vx > 150、vy < −100）、或者一个人按着踏板至少 1 秒同时另一个人过了那扇门，至少一样在这一段里发生。录好的每个手柄单独跑都过不去。
5. **踩板门至少 3 关**（简单、中等、困难各至少一关），门真的挡路：关着的时候一个人绕不过去。踏板离门远到一个人按着够不着门。门那边要有开同一扇门的踏板（或者别的路），先过去的人能把按着的人放过来。可以用 `all`（几块一起按才开，3、4 个人时用）、`hold`（松开还开几秒）、门往上挪当升降台（样板关第二段）。
6. **难度分得开**：简单不放要命的东西，一关一两处配合，`par.seconds` 60 到 120；中等可以有要命的东西，两处配合；困难有要命的东西和会动的东西（动台、转杆），三处配合，`par.seconds` 120 到 240。`par.deathsPerPlayer` 1 到 6。
7. **人多了也得配合**：3、4 个人时一个人过不去的段还是要配合（不能多了人就有人自己爬过去）；可以用 `players` 范围在人多时把坑加宽、多一扇要两块踏板的门。
8. **回放是真玩的**：所有人一起不动不超过 3 秒；每段的时间是玩出来的，不是等出来的。
9. **九关各是各的**：台子上沿按 40 px 一格比，和别的任何一关（闯关、难关、大关、多人的关）重合不超过 60%。不能九关一个套路。
10. **预算**：会动的东西（绳子的节、跷跷板、箱子、动台、转杆、门）≤ 40，平台 ≤ 60，要命的东西 ≤ 40。
11. **验收器和探路**：`scripts/run-levels.mjs` 加多人那一段（读 `levels/multi/`，id 只认 `multi-01` … `multi-09`，可以分批交；上面第 2、4、5、6、8、9、10 条都要查；按人数分组从 2 到 4 个人算，每种摆法都要有回放；最后一行带 `N/9 multi`）。`scripts/probe.mjs` 加多人那一段：不带参数时也查多人的关，规则按第 3 条（简单一段、中等困难两段 1 个人过不去，按 2、3、4 个人的摆法各查）。原来闯关、难关、大关的规则一条都不许放松。踩板门的静态检查（踏板开的门都有、门都有踏板、踏板垫着台子、门在关里）和「每扇门回放里都真开过」已经在验收器里了。
12. **截图和文档**：9 张全关截图到 `docs/levels/multi/<id>.png`（1280 × 720，按 2 个人摆）；`docs/levels/multi/README.md` 写每关的布局（名字、tier、teaches、长 × 高、检查点、par、哪里要配合、靠的是什么、几个人时怎么变）和结果表。
