## 任务

1. **8 关**：表里的 8 个编号，编号、`world`、`tier` 不变，名字（中英文，自己起）、`teaches`、布局全换。写 `"long": true`；中等、困难写 `"stamina": true`（按手酸录）。`teaches` 可以用新的 `tide`、`crumble`、`pendulum`、`wind`（「这关教」的中英文已经在 `src/levels.ts`），也可以用场景原来的词。
2. **路要绕、要长**：尺寸最多 3600 × 2200，所以靠绕，比如「之」字：沿底下往右，从右边爬上去，中间一层往回走，从左边再爬上去，最上面一层往右到终点。也可以是盘旋的塔、来回折的竖井。出生点 `x ≤ 600`，终点在最右边 480 像素里。至少 5 个检查点（6 段，每段 15 到 60 秒），出生点经过每个检查点到终点至少 6000 像素，每个横屏、竖屏都有检查点。4 个人的主回放 150 到 300 秒，`par.seconds` 150 到 360。8 关里至少 2 关有岔路：去下一个检查点有一条快的险路和一条慢的稳路。
3. **新机关，每关至少两样**，加上这个场景自己的机关（验收器的 `SCENES` 照旧查，六关的搭配也照旧）。每样第一次出现的地方要摔得起（在检查点附近、底下有地），后面再放在难的地方；最难的那段前面有个能站着歇的地方。可以这样配（不是非这样）：
   - 后厨：锅里的汤往上涨（涨潮），挂着的铁锅、炒勺（摆锤），抽油烟机一阵一阵吸（阵风），摞着的蒸笼、盘子一踩就塌
   - 雪山：冰水往上涨，荡来荡去的雪球，山口的阵风，一踩就塌的雪檐
   - 老宅：池水往上涨，荡着的灯笼，穿堂风，一踩就塌的朽木、瓦
   - 太空站：能量潮往上涨，荡着的维修舱，气闸泄压的阵风，松了的面板
   - 简单的关不涨潮、摆锤不烫（验收器查）
4. **会动的东西更多、更快**：中等至少 3 个（动台、转杆、摆锤加起来），困难至少 6 个，其中至少 2 个快的（动台 ≥ 120 px/s、转杆 ≥ 1.5 rad/s、摆锤周期 ≤ 2.4 秒）。困难照难关的规矩：要命的东西至少 4 处、每屏都有，两段靠大家（成串挂着或丢队友），录好的每个手柄单独跑都过不去。
5. **手酸**：中等、困难的关开着手酸录。哪段要一口气挂很久（困难两只手 11 秒、一只手 6 秒，中等 18、10 秒），中间就得有能站的歇脚处。
6. **回放**：每关一份 4 个人的回放 `levels/replays/<id>.json`；按人数摆的关每种摆法一份（`.p<人数>.json`）；简单、中等的关另要一份 1 个人的 `.p1.json`（单人模式也玩，1 个人那份只要不超过 `par` 的 2 倍）。原来这 8 关的回放用不上的删掉。每份回放到顶，检查点按顺序，死的次数在预算里（每人 0 到 10，困难 2 到 10），新机关都真用上（涨潮追到最低的人 400 像素以内、每块会塌的台子有人碰塌过、每个摆锤旁边有人过、每块风都刮到过人）。60 Hz，seq 从 0 递增，没有传送、初始速度、改物理、改复活。不要靠一直站着不动拖时间。
7. **红包**：每关 3 个，`npm run envelopes` 从四人回放里挑。
8. **各是各的**：台子上沿按 40 px 一格比，和别的任何一关重合不超过 60%，开头那一屏和同一个场景的关不超过 85%。8 关不能一个套路。
9. **预算**：会动的东西（绳子的节、跷跷板、箱子、动台、转杆、门、摆锤、缆椅每把、钥匙和灯笼）≤ 40，平台 ≤ 60，要命的东西 ≤ 40。
10. **截图和文档**：8 张全关截图到 `docs/levels/<id>.png`（1280 × 720，`npm run levels -- --screenshots`）；`docs/levels/README.md` 里这 8 关各自那一节换成新的：名字、tier、teaches、长 × 高、路怎么绕、检查点、par、新机关在哪、怎么过、结果表，写一句换掉的是哪关（原来几秒）。
11. **CI 的时间**：长关的回放长，PR 里写 `npm run levels` 改之前、改之后各跑了几分钟。
