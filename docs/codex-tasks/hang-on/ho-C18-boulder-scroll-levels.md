## 任务

1. **6 关**：表里的 6 个编号，编号、`world`、`tier` 不变，名字（中英文，自己起）、`teaches`、布局全换。照旧写 `"long": true`；中等、困难写 `"stamina": true`（按手酸录）。`teaches` 可以写新的 `boulder`、`scroll`，也可以写场景原来的词。
2. **搭配**：至少 3 关卷屏（往右卷、往上卷各至少 1 关），至少 3 关有大石头；一关可以两样都有。可以这样配（不是非这样）：
   - `kitchen-26` 简单 · 大汤圆：把大汤圆推进灶台的缝里当桥，再推上蒸笼旁边的踏板
   - `kitchen-28` 中等 · 往上卷：蒸汽从底下追上来，一路往上爬蒸笼、抽油烟机
   - `snow-32` 简单 · 往右卷：雪崩从后面追，一路过雪檐、缆椅
   - `snow-35` 困难 · 雪球：大雪球得三个人推，推到阵风里压住踏板
   - `house-40` 中等 · 往右卷：黑影追着穿过一串屋子，路上找钥匙开门
   - `house-41` 困难 · 往上卷加石绣球：塔里往上卷，中间要把石绣球推上踏板开闸
3. **不能再是三层长台子**：宽过 600 像素的台子最多 3 块，没有宽过 1200 的（验收器 `c18Shape` 查）。路要有起伏、有缝、有落脚点，6 关的路线一关一个样（不能都是「往右、爬上去、往回」）。
4. **推大石头**：
   - 每块石头都得有用：填沟当桥（沟宽和石头直径差不多，推进去正好填平，没有石头过不去或者很难过）、压住踏板开门、垫脚够到高处、当跷跷板的配重，至少用上两种用法（6 关加起来）
   - 中等、困难至少一块要两个人以上推（半径 56 以上）；困难的至少一块半径 75 以上（得三个人）
   - 石头掉出关卡 1.2 秒后回到开局的地方：别让它卡在回不来、推不出去的地方（比如掉进一个出不来的坑里不算掉出关卡），推错了能重来
   - 主回放里每块石头都要真推（离开局的地方至少 200 像素，验收器查）
5. **卷屏**：
   - `speed`：简单 ≤ 45、中等 ≤ 65、困难 ≤ 90（像素/秒）；`delay` 2–10 秒，开局给大家站稳的时间
   - 卷屏的关可以长：往右卷最宽 6400，往上卷最高 4400，顺着卷的方向至少是屏幕的 2.5 倍
   - 检查点顺着卷的方向排，相邻两个（连出生点、终点）隔不到「屏幕长减 400」，屏幕里随时有能复活的地方（验收器 `scrollRules` 查）
   - 别让屏幕把人逼死在等东西的地方：要等的东西（缆椅、门、喷汽）放在屏幕还追不上的时候，或者等的时间短
   - 主回放要跟得上：被甩掉也算死，在死的预算里；1 个人那份回放（简单、中等）也得跟得上
6. **长关的规矩照旧**（`longLevel`）：至少 5 个检查点（6 段，每段 15 到 60 秒），出生点经过每个检查点到终点至少 6000 像素，至少两样新机关（推大石头、卷屏也算），简单的不涨潮、摆锤不烫，中等、困难按手酸录，会动、会转、会荡的东西中等至少 3 个、困难至少 6 个（2 个快的）。困难照难关的规矩：要命的东西至少 4 处、每屏都有，两段靠大家（成串挂着或丢队友），录好的每个手柄单独跑都过不去。这个场景自己的机关和六关的搭配照旧（`SCENES`）。
7. **回放**：每关一份 4 个人的回放 `levels/replays/<id>.json`；按人数摆的关每种摆法一份（`.p<人数>.json`）；简单、中等的关另要一份 1 个人的 `.p1.json`（单人模式也玩，1 个人那份只要不超过 `par` 的 2 倍）。原来这 6 关的回放用不上的删掉。每份回放到顶，检查点按顺序，死的次数在预算里，新机关都真用上。4 个人的主回放 150 到 300 秒，`par.seconds` 150 到 360。60 Hz，seq 从 0 递增，没有传送、初始速度、改物理、改复活。不要靠一直站着不动拖时间。
8. **红包**：每关 3 个，`npm run envelopes` 从四人回放里挑。
9. **各是各的**：台子上沿按 40 px 一格比，和别的任何一关重合不超过 60%，开头那一屏和同一个场景的关不超过 85%。
10. **预算**：会动的东西（绳子的节、跷跷板、箱子、大石头、动台、转杆、门、摆锤、缆椅每把、钥匙和灯笼）≤ 40，平台 ≤ 60，要命的东西 ≤ 40。
11. **截图和文档**：6 张全关截图到 `docs/levels/<id>.png`（1280 × 720，`npm run levels -- --screenshots`；卷屏的关截开局那一屏）；`docs/levels/README.md` 里这 6 关各自那一节换成新的：名字、tier、teaches、长 × 高、路怎么走、石头在哪干什么用、卷屏多快往哪卷、检查点、par、怎么过、结果表，写一句原来是什么样。
12. **CI 的时间**：PR 里写 `npm run levels` 改之前、改之后各跑了几分钟。
