**负责**：Codex　**审查**：Claude Code　**分支**：`codex/ho-c10-kitchen-levels`　**前提**：后厨的机关和画面（A10，`claude/ho-a10-kitchen` 那个 PR）已合并，先把 main 合进分支。C9、C14 没做完也可以做这张：这张卡只动 `levels/kitchen-*.json`、它们的回放和截图、`docs/levels/`，不碰 C9、C14 的文件。

## 为什么

Steve 11-13 定的第三轮：四个新场景，先做中餐馆后厨。后厨的机关 A10 已经做好：**蒸笼喷汽**（定时喷，把站在蒸笼上的人托起来约 360 px）、**端托盘**（一托盘点心端进终点才算过关，端歪了点心就翻、托盘回存档的地方），要命的东西是刀、坐在火上的炒锅、灭蚊灯。这张卡做后厨的六关，放进大厅：简单、中等、困难各两关，单人和多人都玩。

## 任务

1. **六关**：`levels/kitchen-25.json` … `kitchen-30.json`，`"world": "kitchen"`，写 `"tier"`：25、26 是 `0`（简单），27、28 是 `1`（中等），29、30 是 `2`（困难）。名字中英文都要有，自己起，和后厨有关（蒸笼、炒锅、出菜口、洗碗池、冷库……）。`teaches` 是 `steam`（蒸笼喷汽）、`tray`（端托盘）、`combine`，困难那两关也可以是 `spike`、`hot`、`zap`、`mover`、`spinner`、`gauntlet`；30 号是 `combine` 或 `gauntlet`。「这关教」的中英文已经在 `src/levels.ts`。
2. **大小、出生点、检查点**：和闯关一样（横着走的宽 2400 到 3600；攀爬关高 1400 到 2200、至少往上一屏；每屏一个检查点；每段 15 到 60 秒；终点在最后；4 个人都有落脚）。`par.seconds` 简单、中等 60 到 180，困难 60 到 240。
3. **蒸笼至少 4 关**，每摞蒸笼都要有用：后面接着一面抓不住（`"grab": false`）的高墙、或者一道一个人扑不过的坑、或者够不着的高台，坐汽上去才过得去（汽托起约 360 px，到顶时手要抓得到旁边能抓的东西）。几摞错开喷（`phase`）可以做一串台阶。蒸笼的下沿垫在台子上，汽柱下面六成不能有台子挡着。
4. **托盘至少 3 关**，`tray` 写开局放哪，过了检查点以后翻了回哪（每个检查点一个点，最多开局加每个检查点一个）。托盘放的地方要在一直在的台子上，离要命的东西够远，不压在复活的人身上（验收器查）。路上要有端托盘的讲究：要过坑、要坐汽、要从高处递下来，端得不小心就翻；但抓中间、慢慢来端得过去。
5. **两样都有至少 2 关**；刀、炒锅、灭蚊灯各至少 2 关（`hazards` 的 `spike`、`hot`、`zap`；后厨里画出来就是刀、炒锅、灭蚊灯）。
6. **难度分得开**：简单的一两样机关，要命的东西少；中等两三样；困难照难关的规矩（要命的东西至少 4 处、每屏都有，至少一个动台或转杆，两段靠大家，录好的每个手柄单独跑都过不去）。
7. **回放**：每关一份 4 个人的回放 `levels/replays/<id>.json`；按人数摆的关每种摆法一份（`.p<人数>.json`，和以前一样）。**简单、中等的四关另要一份 1 个人的回放** `levels/replays/<id>.p1.json`：单人模式也玩这些关，一个人端着托盘、坐着汽也要到得了顶。每份回放：到顶，用时在 `par.seconds` 的 0.5 到 2 倍（1 个人的那份只要不超过 2 倍），检查点按顺序，每摞蒸笼真把人托上去过，有托盘的关托盘端进了终点（不然不算过关）。60 Hz，seq 从 0 递增，没有传送、初始速度、改物理、改复活。所有人一起不动不超过 3 秒。
8. **红包**：每关 3 个，`npm run envelopes` 从四人回放里挑。
9. **六关各是各的**：台子上沿按 40 px 一格比，和别的任何一关（闯关、难关、后厨的别的关）重合不超过 60%，开头那一屏和别的后厨关不超过 85%。不能六关一个套路。
10. **预算**：会动的东西（绳子的节、跷跷板、箱子、动台、转杆、门）≤ 40，平台 ≤ 60，要命的东西 ≤ 40。
11. **截图和文档**：六张全关截图到 `docs/levels/<id>.png`（1280 × 720，`npm run levels -- --screenshots`）；`docs/levels/README.md` 加后厨一节：每关的布局（名字、tier、teaches、长 × 高、检查点、par、蒸笼和托盘在哪、怎么过）和结果表。
