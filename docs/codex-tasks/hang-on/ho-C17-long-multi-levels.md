# 任务卡 ho-C17 · 多人的长关（换掉每一档最短的那关）

**负责**：Codex　**审查**：Claude Code　**分支**：`codex/ho-c17-long-multi-levels`　**前提**：新机关（A12，#629）、长关的规矩（A13）已合并，先把 main 合进分支。和 C15、C16 文件不重叠，可以同时做。

## 为什么

Steve 11-18 说游戏太简单：「关太短太直」「机关太温和」，选了「新做一批长关替换最短的」；他们几个人在手机上玩的是多人的「一起闯关」，每一档只有 3 关（`levels/multi/`）。量过（2、3、4 个人的回放平均）：每一档最短的是这三关，一路往右走：

| 换掉的关 | 难度 | 现在 2 / 3 / 4 个人用时 |
| --- | --- | --- |
| `multi-01` | 简单 | 52 / 63 / 62 秒 |
| `multi-06` | 中等（这一档最后一关） | 57 / 74 / 96 秒 |
| `multi-07` | 困难 | 99 / 76 / 90 秒 |

这张卡把它们换成长关：路绕来绕去、分成至少 6 段，一个人照旧过不去，用上 A12 的新机关，中等、困难的会动的东西更多、更快。

## 任务

1. **3 关**：表里的 3 个编号，编号、`tier` 不变，名字（中英文，自己起）、`teaches`、布局全换。写 `"long": true`；`multi-06`、`multi-07` 写 `"stamina": true`（按手酸录）。`world` 可以换成四个新场景（`kitchen`、`snow`、`house`、`space`），三关最好各用一个不一样的世界；这个世界自己的机关可以用（蒸笼、托盘、缆车、冰溜子、钥匙、黑屋子、失重区、拉杆）。`teaches` 从多人的词（`chain`、`throw`、`boost`、`hold`、`counterweight`、`relay`、`combine`）和新的 `tide`、`crumble`、`pendulum`、`wind` 里挑，`multi-06` 是这一档最后一关，照旧是 `combine`。
2. **路要绕、要长**：尺寸最多 3600 × 2200，靠绕（「之」字、盘旋的塔、来回折的竖井）。出生点 `x ≤ 600`，终点在最右边 480 像素里。至少 5 个检查点（6 段，每段 15 到 60 秒），出生点经过每个检查点到终点至少 6000 像素，每个横屏、竖屏都有检查点。2、3、4 个人的每份回放 150 到 300 秒，`par.seconds` 150 到 360，`deathsPerPlayer` 1 到 10。
3. **一个人过不去，两个人配合过得去**（C14 的规矩照旧）：简单至少一段、中等和困难至少两段（不能只有第一段）一个人乱按过不去，全量 `npm run probe` 量，结果写进 `docs/levels/multi/README.md` 的 `C14_MULTI_SECTIONS`；这些段里回放真的靠配合（成串挂着、踩着队友、丢队友、按着踏板放人过门）；配合的段数简单至少 1、中等至少 2、困难至少 3；录好的每个手柄单独跑都过不去；所有人一起不动不超过 3 秒。长关段多，配合的地方分散在前后，不要都挤在开头。
4. **新机关，每关至少两样**：涨潮、会塌的台子、摆锤、阵风。和配合搭起来用，比如底下在涨水时得一个按着踏板一个过门、会塌的台子只撑得住一会儿得快点把队友拉上来、两个人一起抓着摆锤荡过大坑、起风时连成串的人得抓牢。每样第一次出现的地方要摔得起，最难的那段前面有能站着歇的地方。简单的关不涨潮、摆锤不烫，也不放别的要命的东西（验收器查）。
5. **会动的东西更多、更快**：中等至少 3 个（动台、转杆、摆锤加起来），困难至少 6 个，其中至少 2 个快的（动台 ≥ 120 px/s、转杆 ≥ 1.5 rad/s、摆锤周期 ≤ 2.4 秒）；困难有要命的东西。
6. **手酸**：`multi-06`、`multi-07` 开着手酸录，要一口气挂很久的地方中间得有歇脚处（成串挂着的人更累：身上每挂一个人累得快 0.6 倍）。
7. **回放**：每关按 2、3、4 个人各一份 `levels/multi/replays/<id>.p<人数>.json`（只有输入，没有传送、初始速度、改物理、改复活），原来的删掉。每份都到顶，新机关真用上（涨潮追到最低的人 400 像素以内、摆锤旁边有人过、每块风都刮到过人，每块会塌的台子至少一份回放里碰塌过）。
8. **每一档照旧有踏板门**：每一档在 2、3、4 个人时都至少有一关有踏板开的门（另外两关都有，换掉的这关可以不用）。
9. **各是各的**：台子上沿按 40 px 一格比，和别的任何一关重合不超过 60%。
10. **预算**：会动的东西 ≤ 40（摆锤也算），平台 ≤ 60，要命的东西 ≤ 40。
11. **截图和文档**：3 张全关截图到 `docs/levels/multi/<id>.png`（1280 × 720，`npm run levels -- --multi-screenshots`）；`docs/levels/multi/README.md` 里这 3 关的那几节换成新的（名字、tier、teaches、世界、长 × 高、路怎么绕、检查点、par、哪里要配合、新机关在哪、几个人时怎么变、结果表，写一句换掉的是哪关），`C14_MULTI_SECTIONS` 跟着改。
12. **CI 的时间**：PR 里写 `npm run levels` 和 `npm run probe -- --quick` 改之前、改之后各跑了几分钟。
