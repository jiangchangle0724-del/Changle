## 为什么

Steve 11-13 定的第三轮：四个新场景，第二个是雪山缆车。机关 A10 已经做好：**缆车**（缆椅、缆车厢沿着缆绳从一个站走到另一个站，站在座板上、抓着横杆都跟着走，到站收进站里，人得先下车）、**冰溜子**（台子写 `slip`，一只手最多抓几秒就滑，得快快倒手），要命的东西是冰锥、篝火、漏电的电轨，一直下雪。这张卡做雪山的六关，放进大厅：简单、中等、困难各两关，单人和多人都玩。

## 任务

1. **六关**：`levels/snow-31.json` … `snow-36.json`，`"world": "snow"`，写 `"tier"`：31、32 是 `0`（简单），33、34 是 `1`（中等），35、36 是 `2`（困难）。名字中英文都要有，自己起，和雪山有关（缆车站、冰瀑、木屋、山顶、雪道……）。`teaches` 是 `lift`（坐缆车）、`slip`（冰溜子）、`combine`，困难那两关也可以是 `spike`、`hot`、`zap`、`mover`、`spinner`、`gauntlet`；36 号是 `combine` 或 `gauntlet`。「这关教」的中英文已经在 `src/levels.ts`。
2. **大小、出生点、检查点**：和闯关一样（横着走的宽 2400 到 3600；攀爬关高 1400 到 2200、至少往上一屏；每屏一个检查点；每段 15 到 60 秒；终点在最后；4 个人都有落脚）。`par.seconds` 简单、中等 60 到 180，困难 60 到 240。
3. **缆车至少 4 关**，每根缆绳都要有用：它跨过一道一个人扑不过的大坑，或者把人送上够不着的高台；上车的站、下车的站都要有台子（下车的台子在缆绳终点前，人得在椅子收进站里之前下来）。缆椅（`chair`）和缆车厢（`cabin`）至少各用一次。椅子一路上不能撞台子（验收器会量）。几根缆绳可以接力（坐一段，换一根）。
4. **冰溜子至少 3 关**：写 `slip`（0.6 到 5 秒）的台子，一般是要爬的冰墙、冰瀑、冰柱。要做到抓得住、但得快快倒手、不能停下来歇；难的地方 `slip` 短一点。冰面站不稳用 `"material": "ice"`（和 `slip` 是两回事，可以一起用）。
5. **两样都有至少 2 关**；冰锥、篝火、电轨各至少 2 关（`hazards` 的 `spike`、`hot`、`zap`；雪山里画出来就是冰锥、篝火、黄黑电轨）。
6. **难度分得开**：简单的一两样机关、要命的东西少、缆车慢；中等两三样；困难照难关的规矩（要命的东西至少 4 处、每屏都有，至少一个动台或转杆，两段靠大家，录好的每个手柄单独跑都过不去）。
7. **回放**：每关一份 4 个人的回放 `levels/replays/<id>.json`；按人数摆的关每种摆法一份（`.p<人数>.json`）。**简单、中等的四关另要一份 1 个人的回放** `levels/replays/<id>.p1.json`：单人模式也玩这些关。每份回放：到顶，用时在 `par.seconds` 的 0.5 到 2 倍（1 个人的那份只要不超过 2 倍），检查点按顺序，每根缆绳都有人坐过（站在座板上或抓着椅子 1 秒），主回放里每块冰溜子都有人抓过。60 Hz，seq 从 0 递增，没有传送、初始速度、改物理、改复活。所有人一起不动不超过 3 秒（等缆椅过来也要在动：可以往前挪、调整位置）。
8. **红包**：每关 3 个，`npm run envelopes` 从四人回放里挑。
9. **六关各是各的**：台子上沿按 40 px 一格比，和别的任何一关重合不超过 60%，开头那一屏和别的雪山关不超过 85%。不能六关一个套路。
10. **预算**：会动的东西（绳子的节、跷跷板、箱子、动台、转杆、门、缆车的椅子每把一件）≤ 40，平台 ≤ 60，要命的东西 ≤ 40。
11. **截图和文档**：六张全关截图到 `docs/levels/<id>.png`（1280 × 720，`npm run levels -- --screenshots`）；`docs/levels/README.md` 加雪山一节：每关的布局（名字、tier、teaches、长 × 高、检查点、par、缆车和冰溜子在哪、怎么过）和结果表。
