- 现状：239 张题（真心话 69 温和 + 66 辣，大冒险 55 温和 + 49 辣），卡片只显示手机自己的语言。2026-11-26 加了公平的瓶子、听天由命、每局换一次题、自己出题（联机匿名、不抽给写的人）、单机跨局先抽没抽过的题；11-04 查出的五个问题都修了。
