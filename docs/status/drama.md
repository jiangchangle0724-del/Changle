# 戏精大赏（drama）现状

- 现状：线上 changle.ca/g/drama-queens。联机一个人也能开（只演独角戏和朗读，不计分），两个人一个演一个猜；每一幕最多演 5 分钟（困难 6 分钟，人多再加，朗读 3 分钟），钟写成 5:00；揭晓和谢幕时主人能换个玩法、回大厅；139 个剧本都有自己的背景图（含 16 个独角戏），大屏的 PK 名单写着怎么演；自己画的人物在台上和小人一样高（#760）；剧情模式联机时观众能喊「换个说法」「换个情绪」、能当场识破锁定嫌疑人（11-26，借了即兴剧和 Spyfall）；难度分新手、进阶、高手三档，新手有台词本和提词器（10 个剧本有了，11-26）。
- 决定：台下喊话每人每幕两次、间隔 8 秒、不计分；当场识破锁了不能改，猜对再 +1；惩罚印章是游戏自己的计时，落下以前主人不能翻下一幕；演员中途离桌，坏人、PK 的一方或者台上没人时这一幕不计分；不到三个人只演独角戏；换个玩法保留今晚的分数。
