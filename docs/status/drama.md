# 戏精大赏（drama）现状

- 现状：线上 changle.ca/g/drama-queens。联机一个人也能开（只演独角戏和朗读，不计分），两个人一个演一个猜；每一幕最多演 5 分钟（困难 6 分钟，人多再加，朗读 3 分钟），钟写成 5:00；揭晓和谢幕时主人能换个玩法、回大厅；131 个剧本都有自己的背景图，独角戏 16 个，大屏的 PK 名单写着怎么演。
- 决定：惩罚印章是游戏自己的计时，落下以前主人不能翻下一幕；演员中途离桌，坏人、PK 的一方或者台上没人时这一幕不计分；不到三个人只演独角戏；换个玩法保留今晚的分数。
- 待办：真手机和电视上一个人试一遍；新的 8 个独角戏配背景图（给 Codex 写卡）；单机一两个人也能玩（照联机的做法）；秘密任务配例子；早先 74 个剧本的英文版换掉中国背景。
- 详细档案：docs/briefs/drama.md。
