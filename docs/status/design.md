# 全站设计 · 状态

- 现状：共用组件在 `site/src/ui/`，规则在 docs/DESIGN.md；详细历史在 docs/briefs/design.md。首页脚本预算 124 KB（现在 123.1）。
- 11-23 游戏顶栏一直有中 | EN（`ui/LangSwitch`：单机 GameHeader、联机 NetFrame、工具页），玩到一半也能换，每台手机换自己的（#768）。
- 11-23 联机：主人点头像能请人离开，被请出的人能重新入座；掉线回来按名字或账号拿回原来的座位（#765）。Mac 上中文输入法输桌号有提示；没声音时顶上提示点一下，电视点开始就有声音（#763）。
- 11-21 站长账号长按网站上的任何字就能改（#759）；大屏的画面不许两指放大，iPhone 会崩（#728）。11-20 哪儿都不许双击放大（#711）。
- `ui/ScreenHints`：竖着玩提示横过来、怎么隐藏工具栏的 3D 演示。iPhone 上的弹层按可见区域定位（`ui/screenAnchor`），滚动锁是计数的（`ui/scrollLock`）。
- 11-19 背景音乐是全站一个电台（`lib/station.ts`），每台手机和电视同一首、同一拍；电视画面和罚酒跟手机一样（#698）。
- 决定：电视画面跟手机共用组件一起换；电台按温哥华时间（固定 UTC-7）；主人请人离开不拉黑，后台踢人才拉黑；回座按名字或账号，不按 IP（一屋子人 IP 一样）。
- 待办：真 iPhone 上试：两台手机听电台是否同一拍、两指放大后双击、长按改字、掉线回座。改字还不管输入框提示、读屏文字、画布上的字和独立应用；6 个独立应用没有横屏和工具栏提示。
- 交出去的（见 briefs/design.md 交给别的对话）：藏在人群里竖着时「请横过来」盖住「回到这桌」；`local_check.py`、`live_check.py` 过期；房间引擎的 claim 和 adopt 知会房间与联机。
