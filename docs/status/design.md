# 全站设计 · 状态

- 现状：共用组件在 `site/src/ui/`，规则在 docs/DESIGN.md；详细历史在 docs/briefs/design.md。11-21 站长账号长按网站上的任何字就能改，所有人一分钟内看到，后台「改字」开关、逐条恢复（#759）。
- `ui/ScreenHints`（GameShell 和 NetFrame 里）：竖着玩提示横过来；横着时一张卡，`ui/ToolbarDemo` 的 3D 手机演示怎么隐藏工具栏，按浏览器分 Safari 18 / 26 / 27 起、安卓、微信，各有「不再提醒」。Safari 版本看 `Version/NN`；等动画的计时器用 `ui/tokenTime` 读时长 token（打包后 400ms 写成 .4s）。
- iPhone 上的弹层按可见区域自己定位（`ui/screenAnchor`），页面滚动锁是计数的（`ui/scrollLock`）。首页脚本预算 124 KB。
- 11-19 背景音乐是全站一个电台（`lib/station.ts` 排表，`lib/nightset.ts` 14 首歌）：按温哥华时间几点、星期几分 7 种心情，每种从开始那一刻起一首接一首，同一时刻每台手机和电视放同一首、对在同一拍上；时间问房间服务器 `/api/time`，手机自己的钟不准也没关系。电视点一下有声音就放（不看音乐设置），有自己配乐的游戏期间停。
- 11-19 电视画面跟手机对齐：林波舞的四种玩法、流氓十三张的牌桌、真心话的盖子、木头人的定住、国王游戏的签筒和宝座；11-20 罚酒也换成手机的大字「喝」加酒杯（#698）。
- 11-20 哪儿都不许双击放大（#711）：主站和 8 个独立应用每个元素 `touch-action: manipulation`，整页在 `<html>` 上听点击（iPhone Safari 只在附近有人听点击时才看 touch-action），写进 AGENTS.md 和 DESIGN.md。11-21 大屏的画面（电视页、只看的手机）不许两指放大，iPhone 放大它会崩（#728）。
- 决定：电视上的画面和动画跟手机一样，手机换新样子时电视那份一起换（共用同一个组件）；电台的时间按温哥华算（固定 UTC-7，BC 全年夏令时，不看手机的时区资料），一桌人在两个城市也听同一首。
- 待办：改字还不管输入框提示、读屏文字、画布上的字和独立应用；6 个独立应用（到此一游、一起跳、抓紧了、藏在人群里、随便、玩什么）没有横屏和工具栏提示；真 iPhone 上要试两样：两台手机听电台是否同一拍，两指放大后双击各处不再放大。
- 交出去的（见 briefs/design.md 交给别的对话）：藏在人群里竖着时「请横过来」盖住了「回到这桌」；`local_check.py`、`live_check.py` 过期了（首页与上线）；电视的改动知会大屏。
