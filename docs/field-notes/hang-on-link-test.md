# 抓紧了 · 联机门实测记录（模板）

联机门（A2 + A4 合并时）：两台手机当手柄，HDMI 接电视，摄像机实测按键到画面 ≤ 80 ms；关一台 Wi-Fi 再开，5 秒内回来。
每做一次填一份，日期写进文件名或下面的表。方案里的延迟预算在 `docs/hang-on.md`「延迟预算」。

## 准备

- 主机：Mac 或 iPad，`cd games/hang-on && npm run dev`，浏览器开它打印的 `http://<IP>:8787/hang-on/`（上线后直接开 changle.ca/hang-on/）。
- 电视：USB-C 转 HDMI 线接主机；电视开「游戏模式」。对照组：AirPlay 镜像。
- 手机：同一个 Wi-Fi，扫主机页的二维码。看主机左上角的延迟表：绿（< 60 ms）/ 黄（< 120）/ 红，有没有「绕路中」。
- 摄像手机：240 fps 慢动作，同一画面里拍到手柄的大键和电视。

## 量什么

| 项 | 怎么量 | 门槛 | 结果 |
| --- | --- | --- | --- |
| 按键到画面（HDMI） | 慢动作里从拇指按下到电视上手套变实心，数帧 ÷ 240 × 1000，量 10 次取中位数 | ≤ 80 ms | |
| 按键到画面（AirPlay） | 同上 | 只记录，写进设置页 | |
| 延迟表准不准 | 延迟表的往返毫秒 vs 摄像机量到的按键到画面（减去渲染一帧约 16 ms） | 差 ≤ 15 ms | |
| 直连还是绕路 | 延迟表上的标签；家里路由器开了「AP 隔离」会全部绕路 | 直连 | |
| 关 Wi-Fi 再开 | 一台手机关 Wi-Fi，数 5 秒再开；秒表量到手柄页显示「已连接」且角色又能动 | ≤ 5 s；断着的时候角色挂着不死 | |
| 微信里打开 | 用微信扫码，看是直连还是绕路 | 直连最好，绕路也要能玩 | |
| 4 个手柄一起 | 4 台手机，主机页右上角的帧时间 | 不掉帧 | |
