# 游戏 · 抓紧了（hang-on）

对话名「游戏 · 抓紧了」。网址 changle.ca/hang-on（已上线；11-11 起首页有它的卡）。档案建于 2026-11-02，A1 做完时写；以后由这个对话维护。

## 它是什么

合作攀爬：每人一个糯米团身体加两条面条胳膊，两只手各自抓，没有跳跃，全靠抓、荡、松手飞。1 到 4 人，所有人到终点才算过关，摔死 1 秒复活在最近的检查点。手机当手柄（局域网 WebRTC 直连，失败走 Cloudflare 中转），电视当画面（Mac 或 iPad 接 HDMI）。没有电视的时候是手机局：一部手机开房自己也玩，大家都在自己手机上看画面。机制可以和原版一样，角色、关卡、美术、名字必须原创；仓库里 docs/ 之外不出现原版的名字。

- 覆盖率：`npm run test:coverage`（`src/physics/` 行覆盖率要 ≥ 80%，C4 时 98%）
- 帧时间：`npm run play` 起着，`npm run perf -- --cpu-throttle 4`（开发页喂 12 关回放，出每关 p50 / p95 / 最差帧；要有显卡的 Chrome，不接 CI）
- 键盘玩物理：`npm run play`（`?level=table-03` 选关，`?players=4` 量帧时间）；录回放：`npm run record`
- 画面只能用眼睛验：开发页或主机页截图，对着 `docs/hang-on.md` 的动效清单一条条看

- 正式版物理用 Rapier2D compat 0.21，主机是唯一跑物理的地方，手柄只发输入。
- 挂着时摇杆指「身体想去哪」，不是「手指哪」；身体到抓点必须有系绳。
- 三道验收门：手感门（A1）、联机门（A2 + A4）、聚会门（上线前）。
