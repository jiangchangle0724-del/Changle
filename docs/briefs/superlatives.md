# 游戏 · 最佳称号（superlatives）

对话名「游戏 · 最佳称号」。网址 changle.ca/g/superlatives。档案建于 2026-11-02，从仓库里的文档和提交记录整理；以后由这个对话维护。

## 它是什么

每轮一个称号，大家投票选人，票最多的拿奖也喝。最后有颁奖典礼。

3 到 15 人。单机：传手机偷偷投票（点一个人，再按「投好了」才算，点错能改）、一起指，或者偷偷问；第一票投出前可以换题、自己出题。联机：每人自己手机投，主人可以换题、自己出题、提前揭晓；也能开偷偷问；大屏有自己的画面。

## 定过的事

- 每个奖揭晓 2.6 秒后（单机 2.9 秒），得奖的人手机上落惩罚印章。印章是游戏自己的计时器（2026-11-11 起，之前是房间服务器的延时惩罚），所以主人的「下一个奖」要等印章落了才亮，服务器也不接受更早的点击；颁奖典礼的「再来五个奖」同样等 3.2 秒的全场干杯。联机测试要等印章落下、点掉再按「下一个奖」（#97）。
- 单机提前按「下一个奖」：印章马上落，点掉之后才到下一个奖（#141）。
- 每张选票带选票号（`ballot`，换题、自己出题、下一轮都是新号）。手机锁屏回来那一秒投的票带着旧号，服务器不算。
- 单机的颁奖典礼也有全场干杯的印章，和联机一样（2026-11-11 定的，Steve 说修全部问题，没单独说这条；要改回去只删 `Superlatives.tsx` 里的 `toast`）。
- 得奖的人揭晓时离桌：还是得奖者，名字头像照旧，颁奖典礼仍列出他的奖；不再给他落印章。
- 单机传手机投票：点一个人只是选中（打勾），底部「投好了，交给下一位」（最后一个人是「投好了，揭晓」）才算票，点错了点别人就改。2026-11-20 定的：和话剧的传手机投票一样先选后交，之前点一下就算、没法改。要改回去只看 `Superlatives.tsx` 里的 `pick`。
- 单机也能换题、自己出题，按钮在奖牌下面（和联机主人的一排一样），第一票投出后就收起；一起指的模式一直在。自己出的题只显示一种文字（和联机一样）。
- 题库（2026-11-26，Steve 选的升级，借鉴同类应用的分类题库）：开局选题库，至少开一个。联机多了一个 `setup` 阶段：主人在自己手机上选题库和几个奖（5/8/12，之前联机固定 8 个），按「开始颁奖」才发第一题；别人的手机和大屏只看主人选了什么。引擎动作 `config { packs, total }`、`start`，都只有主人在 setup 阶段能发，别的时候 `api.quiet()`。部署时正在玩的老局没有 `packs` 字段，按全部称号发牌。
- 揭晓花样 + 读心术奖（2026-11-26，同一批升级）：`flavor.ts` 一处算，单机、联机、大屏都用。得奖者下面最多一行：平票 > 同一个人连拿 3 个（提醒换个人，借桌游圈的 someone-else 规则）> 全票（除得奖者自己外所有投了票的人都投他）> 一票险胜；再一行「请发表获奖感言」。引擎记 `hits`（投中得奖者的次数）和 `streak`（连拿），颁奖典礼上投中最多的人得「读心术奖」（并列一起，一个没投中就不发）；一起指的模式没有选票，没有读心术奖。
- 颁奖海报（2026-11-26，同一批升级）：颁奖典礼页的「颁奖海报」按钮，`poster.ts` 在 canvas 上画一张 1080 宽的图（每个人、拿的奖、全场最佳、读心术奖、日期、changle.ca/g/superlatives），`PosterSheet.tsx` 用 `ui/Sheet` 展示并交出去，交法照抄两清的结清图（`split/share.ts`）：能分享文件的手机走系统分享，电脑下载，微信里长按图片保存。头像颜色和座位一样（`account/Avatar` 的 `AV_COLORS`/`colorFor`），不画账号头像图片（跨域会污染 canvas）。单机、联机每台手机都能存自己的一张。
- 偷偷问（2026-11-26，同一批升级，借桌游圈的 Paranoia）：开局选「偷偷问」。每轮一个人（出题人）自己看题，当众说一个名字再在手机上点TA；被点名的人「喝一口看题」（落印章，印章上不写题）或「不看」；被点名的人问下一题。题从点名那一刻就记在被点名的人的奖架上，看没看都一样，颁奖典礼全揭晓。引擎：`mode: "whisper"`，阶段 `ask → dare → peek`，动作 `name`、`peek`，出题人也能 `skip`/`custom`；出题人 60 秒不点名换下一个座位问，被点名的 45 秒不答算不看；出题人离桌换人，被点名的离桌算不看。`view` 里题对不该看的人是「？？？」（大屏永远是）。单机：`whisper-pass → ask → dare → peek-pass → peek`，存进度时 ask 退回 whisper-pass、看过题的 peek 退回 peek-pass（和选票一样，不把私密的题留在存档里）。没有读心术奖和揭晓花样（没有选票）。

## 还剩什么

- 联机小屏手机上，主人的揭晓画面会被共用的联机框架往下滚到「下一个奖」按钮，得奖的人可能被顶出屏幕上沿（`site/src/online/useActionsInView.ts` 的「把新按钮带进视野」）。客人的手机没这个问题。要改得由房间对话来，见下面。

## 交给别的对话

- 房间（联机框架）：
  - 顶栏「这桌」按钮的读屏名字不含上面显示的人数，axe 报 `label-content-name-mismatch`（`NetFrame.tsx` 的 `.table-btn`）。

  - 联机框架没有像游戏壳那样的底部动作区：主人的主按钮在正文里，小屏上「带进视野」会把画面滚走（见上面）。
  - `scripts/watch_players_check.py` 的最佳称号一段还按旧样子检查只看的人的手机（期望看到选票），现在只看的人看的是大屏画面（#149），这段要改。
- 全站设计（游戏壳）：底部动作区的按钮一换，原位置的新按钮会接到连点的第二下（`moment.ts` 里 `useFreshTapGuard` 是本游戏自己的挡法，350 毫秒内 `aria-disabled` 并忽略点击，脚本会自动等它过去）。别的游戏也会遇到，放进壳里更好。
