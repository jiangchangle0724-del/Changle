# 平台 · 全站设计（design）

对话名「平台 · 全站设计」。档案建于 2026-11-02，从仓库里的文档和提交记录整理；以后由这个对话维护。

## 它是什么

整个网站的样子：夜场灯光风格，颜色、字体、间距、圆角、阴影、动画都定成设计 token；12 个共用组件；UI 计划（docs/ui-plan.md）的分工和进度。

## 文件

- 设计 token 和全局样式：`site/src/styles/`（`tokens.css`、`global.css`）
- 共用组件和预览页：`site/src/ui/`（预览页 `site/ui-preview.html`）
- Codex 的 UI 任务卡：`docs/codex-tasks/ui-*.md`

## 定过的事

- 只有夜间配色。
- 颜色、字号、间距、圆角、阴影、时长都从 `tokens.css` 取（`var(--…)`），不裸写。
- 每个游戏有自己的灯光颜色（gel），进了游戏房间亮这个颜色。首页的游戏卡按 5 类上色，分法 2026-11-02 Steve 定，写在 docs/DESIGN.md 类型色一节。
- Codex 的人群游戏（PR #5）先放着（Steve 2026-11-02）；同一天定了改名藏在人群里 · Hide in the Crowd，接进 changle.ca（档案 hide-crowd.md）。
- 中文行高、可以双指缩放、点击区至少 44px（UI 计划 C4，#93、#94）。

## 还剩什么

- 改了画面的 PR：先问 Steve，再打 `update-screenshots` 标签，机器人提交新截图后，再推一个提交（空提交也行）让检查重跑，绿了再合并。林波舞的首屏截图每次可能差几个像素：两个 PR 都改了它时，后合的那个取 main 的版本。画面里随机的东西在截图对比里不画（还占着位置）：`site/tests/visual/screens.spec.ts` 的 `HIDE`。不用 Playwright 的遮罩：遮罩按元素的大小画，随机的字长短不一，遮罩也跟着变。
- Codex 标成草稿的 PR，REST 改不了草稿状态，用 `POST /repos/{owner}/{repo}/pulls/{n}/ccr/ready_for_review`（GraphQL 在这里不能用）。
