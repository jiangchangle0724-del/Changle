两清是 changle.ca 的分账工具：一群人出去玩，谁付了什么记一笔，最后告诉每个人该给谁多少钱。发一条链接就能加入，不用先注册；登录后账本存在云端，每人 500 MB。网站不碰钱，转账大家自己用 e-Transfer 或微信。

## 第一版做什么

第一版做完整的一圈：开账本、拉人、记账、结清，加上小票照片。做完测过再上工具页，之前先藏着。

| 功能 | 怎么做 |
| --- | --- |
| 开账本 | 起个名字，填成员名单，选结算货币（默认加元） |
| 邀请加入 | 一条链接加一个二维码；点进来选「我是谁」，不用注册 |
| 记一笔 | 金额、谁付的、分给谁、一句备注。默认自己付、全员平分，要改才展开 |
| 三种分法 | 平分；按份数（一家三口算 3 份）；按金额（各填各的） |
| 多币种 | 每笔可以换货币（站内已有的 11 种），按当天汇率折成结算货币，汇率能手改 |
| 谁欠谁 | 每个人一个净额：该收多少，或者该给多少 |
| 结清 | 算出最少的几笔转账；转完点「已转」。收款方式只展示（e-Transfer 邮箱、微信收款码） |
| 改和删 | 成员都能改，每次改动留记录；删掉的 30 天内能恢复；结清后可以锁账本 |
| 同步和离线 | 一个人记了，其他人的手机几秒内看到；没信号照样记，联网后自动补上 |
| 小票照片 | 每笔能挂照片，登录后才能传，占自己的 500 MB |
| 分享和导出 | 结清方案生成一张图，发微信群；账目导出 CSV |

第二版，第一版用顺了再做：

- 拍小票自动认出每一项，点菜名分给人
- 公账：大家先交团费给一个人，花完多退少补
- 一笔由几个人一起付
- 给没结清的人发邮件提醒

不做：

- 不经手钱：不接支付，不存银行卡，转账大家自己转
- 不放广告，不限笔数，不卖会员
- 不做合租的每月账单、预算图表、银行流水导入

## 设计：高端简约怎么落地

高端靠克制，不靠装饰：只有三屏，一屏一个主按钮，数字最大。颜色、字体和按钮全用主站现成的夜场配色和 12 个组件，一眼认得出是 changle。

三屏线框图（原文是图）：三屏做完所有事，主按钮都在拇指下。示例数据；真实样子用主站的夜场配色，下一步出能点的小样。

| 屏 | 从上到下 | 底部的主按钮 |
| --- | --- | --- |
| 1 账本 | 返回、账本名（惠斯勒周末）、右上角菜单；「账目」「结清」两个页签；你的净额，页面上最大的字（你该收 $42.50）；5 个人 · 共花 $387.50；账目一行一笔：晚饭，小王付，5 人平分，$186.00；油费，你付，5 人平分，$120.00；早餐，阿美付，5 人平分，$81.50 | 记一笔 |
| 2 记一笔 | 关闭；金额，页面上最大的字（$86.40，加元）；谁付的：你；分给谁：全部 5 人平分；备注：午饭；数字键盘 | 记好了 |
| 3 结清 | 返回；「4 笔转账，全部两清」，最少的转法，照着转就行；Jason 给小王 $77.50（已转）；小李给小王 $31.00（还没转）；小李给你 $42.50（还没转）；小李给阿美 $4.00（还没转） | 把结清图发到群里 |

三屏的顺序就是用的顺序：看账，记一笔，结清。图里的数字是同一个示例账本，对得上。

1. 只有三屏：账本、记一笔、结清。成员、改动记录、存储、导出都收进右上角的菜单。
2. 记一笔两次点按：点「记一笔」，输金额，点「记好了」。谁付的默认是自己，分给谁默认全员平分，要改才展开。
3. 一屏一个主按钮，放在底部拇指够得到的地方。
4. 数字是主角：金额用页面上最大的字、等宽数字。欠款用字说清楚（你该收 $42.50），不靠红绿两色。
5. 颜色只用工具的琥珀色一盏灯，不加新颜色。
6. 动效只有三处：一笔落账、净额数字滚动、全部结清的那一下。别的都安静。
7. 没有广告、升级弹窗、注册墙、红点。
8. 按钮和提示中英文都有，跟站内的语言开关走；人名和备注原样显示。
9. 邀请链接、e-Transfer 邮箱和要转的金额旁边都有复制按钮，因为站内的字不能长按复制。

两个量得出来的标准：从点开链接到记下第一笔不超过 30 秒；记一笔不超过 10 秒。

## 多人加入：一条链接，不用注册

加入不用注册，开账本要登录：门槛只放在组织的那一个人身上。

1. 开账本的人登录，填好成员名单，把链接或二维码发到群里。
2. 朋友点开链接，在名单里点自己的名字；名单里没有就加上自己。马上能看账、记账。
3. 朋友以后登录了，这个名字就绑到他的账号上，换手机还在；不登录就只认这部手机。

| 能做什么 | 不登录 | 登录 |
| --- | --- | --- |
| 看账、记账、改账 | 可以 | 可以 |
| 开新账本 | 不行 | 可以 |
| 传小票照片 | 不行 | 可以，占自己的 500 MB |
| 换手机、换浏览器 | 要重新点链接选名字 | 账本都在 |
| 我的账本列表 | 只在这部手机上 | 跟着账号走 |

- 链接就是钥匙：一长串猜不到的字符，不是 4 位桌号。开账本的人可以换链接（旧的作废）、锁账本。
- 名单上的人不用都进来：一个人替大家记完也行，没进来的人照样算在里面。
- 一个账本最多 30 人。
- 登录用主站的账号（邮箱验证码），不另做一套。

## 云存储：每人 500 MB 怎么算

500 MB 只算你自己传的照片和文件，够存大约 1,600 张小票；账目的文字不占额度。对小票来说这个额度很宽：一次旅行 30 张小票约 9 MB，500 MB 够 50 多次旅行。

| 问题 | 规则 |
| --- | --- |
| 什么占额度 | 你传的小票照片、PDF、收款码图片。传到哪个账本都算在你头上 |
| 什么不占 | 账目本身（金额、备注、改动记录）。1,000 笔账大约 1 MB，不计 |
| 一张照片多大 | 传之前在手机上压到长边 1600 像素，大约 300 KB；单个文件上限 10 MB |
| 快满了 | 用到 400 MB 提醒一次 |
| 满了 | 不能再传照片，记账不受影响；删旧照片或整个旧账本就腾出来 |
| 在哪看 | 菜单里的存储页：已用多少，哪个账本占得最多 |
| 谁能看照片 | 只有那个账本的成员。照片没有公开网址 |
| 删账本、删账号 | 照片一起删，额度退回；别人传的照片退别人的额度 |

额度由服务器在收照片的那一刻核对，手机改不了。每天夜里对一次账：记的用量和实际文件对不上，以实际为准。

额度先记在两清自己的服务器里。以后别的工具也要存东西，再搬到账号那边，变成整个账号的总额度。

## 算账规则

钱按「分」存成整数：每一笔分完加起来一定等于原价，结清后每个人一定归零。下面的例子我都写代码算过。

| 规则 | 怎么做 | 例子 |
| --- | --- | --- |
| 平分 | 总额除以人数；除不尽的几分钱按名单顺序一人一分，下一笔从下一个人开始，长期不偏谁 | $100 三人：33.34、33.33、33.33 |
| 按份数 | 按每人的份数比例分，尾差同上 | $90，一家三口 3 份加朋友 1 份：67.50、22.50 |
| 按金额 | 各填各的，加起来必须等于总额，差多少当场提示 | $80：小王 50，阿美 30 |
| 多币种 | 每笔存原币金额和记账当天的汇率，折成结算货币再分；以后汇率变了，旧账不变 | 30 美元的晚饭，汇率 1.40，记成 $42.00 加元 |
| 没有小数的货币 | 日元、韩元不带小数，位数跟货币走 | 3,000 日元三人：各 1,000 |
| 净额 | 每人的净额等于自己付出去的减去自己该承担的 | 付了 $120，该承担 $77.50，该收 $42.50 |
| 结清 | 配成最少的几笔转账。16 人以内算真正最少的方案，更多人用近似算法 | 5 个人最多 4 笔 |
| 已转 | 「已转」记成一笔特殊的账，双方都看得到，能撤销 | 小李给你 $42.50，点已转，你的净额归零 |

## 技术架构

画面放在主站里，服务器是一个新的 Worker，照片放 R2。登录、汇率、设计组件都用现成的，全部跑在你现在的 Cloudflare 账号上。

部件图（原文是图）：账目和照片分开存，登录和汇率用现成的。

| 部件 | 是什么 |
| --- | --- |
| 手机上的两清 | changle.ca/split，主站里的新页面，用主站现成的组件，没信号也能记 |
| 新服务器 `split`（新做的） | 接 changle.ca/split/api，里面有下面两种对象 |
| 账本对象，每个账本一个 | 账目、成员、改动记录；自带数据库；有人记账就推给所有人 |
| 账号对象，每个账号一个 | 我的账本列表；已用空间；传照片前先查额度 |
| 房间服务器（现成的，不用改） | `/api/me`：这个登录凭证是谁；`/api/fx`：11 种货币的汇率 |
| R2 存照片 | 桶 `split-files`，私有；只有账本成员能看 |

图上的四条线：

1. 手机到新服务器：记账、同步、传照片。
2. 手机到房间服务器：登录走主站账号。
3. 新服务器到房间服务器：认人、查汇率。
4. 账号对象到 R2：额度够才存。

手机只和新服务器说话。新服务器向房间服务器认人、查汇率；照片先过额度这一关，再进 R2。

| 部件 | 放在哪 | 归谁 |
| --- | --- | --- |
| 画面：三屏和弹层 | `site/src/split/`，用主站的组件和 token，按需下载，不占首页预算 | 这个工具的对话 |
| 算账：分摊、尾差、结清 | `site/src/split/core/`，纯计算，只写一份，手机和服务器都用它 | 这个工具的对话 |
| 服务器 | `tools/split/`，Worker `split`，接 changle.ca/split/api | 这个工具的对话 |
| 账本数据 | 每个账本一个 Durable Object，自带数据库，负责实时同步 | 这个工具的对话 |
| 账号用量 | 每个账号一个 Durable Object：我的账本、已用空间 | 这个工具的对话 |
| 照片 | R2 桶 `split-files`，私有 | 这个工具的对话 |
| 登录 | 主站账号；服务器拿登录凭证问房间服务器的 `/api/me` | 账号对话，不用改 |
| 汇率 | 房间服务器的 `/api/fx` | 房间对话，不用改 |
| 共用文件 | `router.ts`、`App.tsx`、工具页的入口卡、HANDOFF 和档案目录的表 | 平台对话的文件，只加自己那一行 |

画面为什么不像随便那样做成独立应用：随便独立以后样子和主站不一样，现在要专门返工换皮（UI 计划 C3，还没开始）。两清从第一天就用主站的组件，不走这条弯路。

账本数据为什么用 Durable Object：仓库里的桌子、账号、随便都是这个做法，Cloudflare 免费版能用；一个账本的改动排着队一笔一笔进，不会两个人同时记把账记乱。

## 老手会多做而你没要求的事

做过记账软件的人会先把这八件事定下来，因为事后补最贵。

1. 离线记的账不重复也不丢：每笔在手机上就有自己的编号，补传两次服务器也只认一次。
2. 账本一律存在服务器上，手机上那份只是副本。iPhone 的 Safari 会把 7 天没点过的网站的本地数据清掉（[WebKit 的规则](https://webkit.org/tracking-prevention/)）。
3. 两个人同时改同一笔：后改的生效，前一个版本留在改动记录里，能改回去。
4. 网站不经手钱还有一层原因：在加拿大，替别人汇款转账的业务要向 FINTRAC 登记成货币服务商（[FINTRAC 的说明](https://fintrac-canafe.canada.ca/msb-esm/msb-eng)）。只记账就不涉及。这是我读官方页面的理解，不是法律意见。
5. 多数人会从微信群点进来，所以每一期都在微信自带的浏览器里测，苹果和安卓各一遍。
6. 防滥用：每个账号每天最多开 10 个账本，上传限速，只收图片和 PDF。
7. 隐私：消费记录和小票是个人信息。照片只给成员看；能导出自己的数据；删账号时自己传的照片一起删，账目里只留名字。站长后台只看账本数和总用量，不看别人的账。
8. 结清图上写明生成时间，后来又记了新账就提示「这张图过期了」，免得照旧图转错钱。

## 成本

第一版每月 0 元，前提是所有人的照片加起来不超过 10 GB。超过以后每 GB 每月 0.015 美元。按你现在的 Cloudflare 免费版算。

| 用到的 | 免费额度 | 两清大概用多少 | 超了以后 |
| --- | --- | --- | --- |
| [R2](https://developers.cloudflare.com/r2/pricing/) 存照片 | 10 GB，每月 100 万次写、1,000 万次读 | 一次旅行 30 张小票约 9 MB；1,000 次旅行约 9 GB | 每 GB 每月 0.015 美元，流量不收钱 |
| [Durable Objects](https://developers.cloudflare.com/workers/platform/pricing/) 存账目、做同步 | 每天 10 万次请求，共 5 GB | 1,000 个账本各 100 笔约 100 MB | 当天暂停，不扣钱 |
| Workers 接请求 | 每天 10 万次，全站共用 | 一个人记一晚上账几十次 | 当天暂停，不扣钱 |
| 登录邮件、汇率 | 已经在用 | 不新增 | 不变 |

最坏的情况：一个人把 500 MB 传满，每月多花 0.0075 美元，不到 1 分钱。100 个人都传满是 50 GB，每月 0.60 美元。

开通 R2 要在 Cloudflare 账号里走一次开通流程（[官方说明](https://developers.cloudflare.com/r2/get-started/)）。流程里可能要你绑一张付款的卡。这一步改 Cloudflare 设置，等你点头，到第三期才需要。

第二版的小票识别按张收费，用你已有的 Google 钥匙，开工前再核价、设每月上限。

## 分期和验收

分三期做，每期一道验收门，过了才往下。三道门都过了，两清才从藏着变成工具页上的一张卡。

路线图（原文是图）：三期都过了验收门，才上工具页。

| 期 | 做什么 | 验收门 |
| --- | --- | --- |
| 第一期 算得对 | 算账代码，单独测；能点的三屏小样；数据只存在手机上 | 1 万个随机账本全部归零；两份独立算法结果一致；你用手机记 10 笔觉得顺 |
| 第二期 一起记 | 服务器、链接加入、登录；实时同步，离线补记；多币种 | 5 部手机同时记，结果一致；断网记 3 笔，不丢不重；在微信里打开能用 |
| 第三期 存得住 | 小票照片，每人 500 MB；存储页；分享图，导出 CSV | 传满 500 MB 就传不上去；删照片，额度退回；删账号，照片真的没了 |

每一期做完就合并，但入口先不放出来，线上只有知道网址的人打得开。「两份独立算法」的意思是：我写一份结清算法，另请 Codex 独立写一份，拿同样的一万个账本各算一遍，结果对不上就是有 bug。

## 要你定的 4 件事

别的我都按上面写的做，这 4 件只有你能定。

| 事项 | 我的建议 | 另一个选项 |
| --- | --- | --- |
| 名字和网址 | 两清 · All Square，changle.ca/split | AA 一下 · Split It，或者你起 |
| 开账本要不要登录 | 要，加入不用。账本永远找得回来 | 不登录也能开，但 30 天没人登录保存就自动删 |
| 开通 R2 存照片 | 同意开通。10 GB 内免费，超出每 GB 每月 0.015 美元 | 先不开：第一版不带小票照片，500 MB 也先不做 |
| 先后顺序 | 按你之前定的，先做约时间，两清排第二 | 两清插到前面 |

## 下一步

1. 你定上面 4 件事。
2. 按档案目录的规矩新开对话「工具 · 两清」。第一个 PR 建档案 `docs/briefs/split.md`，把这份方案存进仓库 `docs/split.md`，在工具页登记但先藏着。
3. 先出一个能点的三屏小样：夜场配色，真的能算账，数据只存在手机上。你在自己手机上记 10 笔，觉得顺再接服务器。
