# changle 设计系统

主站、/eat 和以后的每个工具、游戏共用这一套。三样东西各管一件事：

- `site/src/styles/tokens.css`：所有的值，颜色、字号、间距、圆角、阴影、动效。只在这里定义。
- `site/src/ui/types.ts`：12 个组件的接口。组件已在 `site/src/ui/` 实现，预览在 `site/ui-preview.html`。
- 这份文件：规则，和为什么。

`site/DESIGN.md` 写的是现在线上的样子和创意方向：夜里的一个房间，每个游戏一盏色灯。这个方向不变。
迁移做完之前，看现状读它，写新东西按这份。旧值怎么换成新 token，见 [ui-inventory.md](ui-inventory.md)。
整体方案在 [ui-plan.md](ui-plan.md)。

## 三条标准

每个改动都要说得出它改善了哪一条。

- 一致：任何一页，一眼认出是 changle。
- 可读：3 米外的电视、灯光暗的客厅、390 宽的手机，都读得清。
- 可信：点了就有反应，错了有退路。

## 写法规则

1. token 只在 tokens.css 里定义；组件只引用 token；页面只用组件。
2. 审查时搜到裸写的 hex 颜色或 px 字号就打回。`site/tests/tokens.test.ts` 对 `src/ui/` 自动查。
3. 例外只有三种：
   - 游戏画面里的道具颜色（纸、血红、金、牌面）：在那个游戏样式文件的开头定义成局部变量，
     比如 `.dm { --dm-blood: #7a1428; }`，规则里只用变量。不进全站 token。
   - 色板数据和 SVG 插画（头像色、转盘色、演出角色）：写在 TS 里有名字的数组中，不散落在各处。
   - 二维码和牌面的纯白：`--color-paper`。
4. 新代码用语义名（`--color-*`、`--type-*`、`--text-*`、`--space-*`、`--shadow-*`、`--dur-*`），
   不直接用色板名（`--dusk-2`、`--gel-coral`）。色板只给 tokens.css 自己和游戏画面用。
5. 界面审查按 Vercel 的 Web Interface Guidelines
   （<https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md>）
   加上这份文件。

- 动脑的 violet 和主站的强调紫是同一个色：强调紫只用在房间光、焦点和链接上，不做卡片底色。
- 喝酒局的 coral 和 Stop Red 很近：Stop Red 只出现在惩罚和错误上。

### 对比度

正文要 4.5:1，大字（24 以上，或 19 以上的粗体）要 3:1。

| 字 \ 底 | 页面 | 弹层 | 面板 | 静按钮 |
| --- | --- | --- | --- | --- |
| moon | 17.6 | 16.0 | 14.3 | 12.4 |
| haze | 9.5 | 8.7 | 7.7 | 6.7 |
| fog | 4.8 | 4.4 不够 | 3.9 不够 | 3.4 不够 |

- fog 只放在页面底色上，或者只用于占位文字和不能点的状态。面板上的次要数字用 haze。
- 任何亮色（gel、类型色、成功、警告、危险）上的字用夜色，最低是 Stop Red 上的 6.0:1。
  Stop Red 上的白字只有 3.2:1，所以危险按钮的字用夜色。

## 字体

- 拉丁：Figtree 写正文，Unbounded 写标题。两个可变字体自带，共 71 KB。
- 中文：用每台设备自己的字体，不自带中文字体文件（一套就要几 MB）。`--font-zh` 的顺序：
  PingFang SC（苹果）、Hiragino Sans GB（老的苹果电脑）、Noto Sans SC / Noto Sans CJK SC /
  Source Han Sans SC（安卓、Linux、装了思源黑体的电脑）、Microsoft YaHei（Windows）。
  所以 iPhone、安卓、Windows 上的中文本来就长得不一样，这是有意的取舍。
- 中文标题：Unbounded 没有中文字，中文自动落到系统粗体（800）；英文副标用 Unbounded。
- 行高：中文正文 `--leading-zh` 1.65，英文正文 `--leading-en` 1.5，标题、比分、桌号 `--leading-tight` 1.1。
  正文直接写 `line-height: var(--leading)`，它跟着页面语言（`<html lang>`）在两个值之间切换。
- 双语：标题两种语言同时出现，读者的语言在前、字大，另一种在后、小两档。正文跟着语言开关切换。
- `lang`：中文内容包在 `lang="zh-CN"` 里，英文在 `lang="en"` 里，行高和断行跟着它走。
  浏览器支持 `text-autospace` 就打开，中英文之间自动留一点空。（C4）
- 会跳的数字（秒数、分数、人数）用等宽数字：`font-variant-numeric: tabular-nums`。

## 字号

| token | 手机 | 桌面（1440 宽） | 用在 |
| --- | --- | --- | --- |
| `--text-xs` | 12 | 12 | 标签、小字。最小就是 12 |
| `--text-sm` | 14 | 14 | 提示、次要文字 |
| `--text-md` | 16 | 16 | 正文、按钮、输入框（输入框小于 16，iPhone 会放大页面） |
| `--text-lg` | 18 | 18 | 大按钮、引导句 |
| `--text-xl` | 22 | 26 | 弹层标题、题目 |
| `--text-2xl` | 28 | 34 | 页面标题、比分 |
| `--text-3xl` | 40 | 48 | 大标题、桌号 |
| `--text-4xl` | 64 | 64 | 电视画面（`/tv`）、巨型数字 |
| `--text-poster` | 88 到 156，跟屏宽 | 156 | 只给惩罚盖章和倒计时 |

- 后三档标题在 370 到 1440 宽之间平滑变大（`clamp`）。桌面最大是手机的 1.2 倍，这个倍数是我定的，可以调。
- 用 `rem` 写：客人把浏览器字号调大，页面的字跟着大。
- 现在的 49 种 px 值各落哪一档，见 ui-inventory.md 的字号映射。规则是落到最近的一档，正好在中间时，
  18 以下往大取（为了读得清），18 以上往小取（为了不撑破版面）。

## 间距

4 的倍数，名字里的数字乘 4 就是像素：`--space-1` 4、`--space-2` 8、`--space-3` 12、`--space-4` 16、
`--space-6` 24、`--space-8` 32、`--space-12` 48。

页面左右 `--gutter` 16，卡片里面 `--pad-card` 16，区块之间 `--gap-section` 24。

## 圆角

保留现在的五档：`--r-small` 10、`--r-field` 14、`--r-panel` 20、`--r-tile` 24、`--r-sheet` 28（只圆上面两个角），
再加 `--r-pill` 999，所有能按的东西都是胶囊形。

## 层次

- `--shadow-flat`：面板和芯片。一圈细描边，顶上一线高光。
- `--shadow-float`：离开页面浮起来的东西，比如拖着的牌、提示条。
- `--shadow-sheet`：弹层和对话框。
- `--glow`：这是光，不是影子。只给亮着的东西，颜色就是它自己的颜色（主按钮、惩罚按钮）。
- 描边（输入框、头像圈、轮到谁的圈）归组件自己管，不算阴影。
- 玻璃模糊：`--blur-scrim` 用在弹层后面，`--blur-glass` 用在顶栏。同一屏最多两处。

## 动效

- 时长：进场 `--dur-enter` 200 毫秒，离场 `--dur-exit` 150，强调 `--dur-emphasis` 400。
- 缓动只用 `--ease-out`；`--ease-pop` 带一点回弹，只给新出现的小东西。
- 每个动效要回答「它告诉用户什么」，答不上来就删。
- 惩罚盖章是全站最响的一刻，别的都安静。
- 减弱动效：系统打开「减弱动态效果」时，tokens.css 把 `--motion-shift` 变成 0，强调变成 200 毫秒。
  组件的滑入写成 `translateY(var(--motion-shift))`，减弱时自动只剩淡入淡出，不用每个组件单独判断。
- 实现以 CSS 动画为主。GSAP 只留给字标和结算页（A6 处理其余的）。
- 长过 600 毫秒的是游戏编排（倒计时、转盘、循环），留在游戏里，不用 token。

## 触控、图标、布局

- 能按的东西最小 `--tap` 44×44；几个挨得很近的地方用 `--tap-crowded` 48。
- 图标用 lucide 线稿，`--icon-sm` 24 和 `--icon-lg` 48 两档。不用 emoji 当图标。
- 手机一栏，最宽 `--page-max` 560。720 以上两栏：左边今晚的人和联机，右边游戏 3 列；1200 以上 4 列（A4）。
  断点没法写成 CSS 变量，统一用 `@media (min-width: 720px)` 和 `@media (min-width: 1200px)`。
- 游戏壳（`site/src/games/GameShell.tsx`，A5）：顶栏 `--bar-h` 56 加顶部安全区，底部动作区 `--dock-h` 72 加底部安全区。
  - 顶栏：返回、两种语言的游戏名、轮次或剩余秒数（用字写：第 3 轮、还剩 12 秒）、声音、玩法，最多再加一个游戏自己的按钮（图标加名字）。
    手机上声音、玩法和那个按钮收进「⋯」，菜单里每项都写名字；720 宽以上全摆在栏里。
  - 玩家条：今晚的人。轮到谁谁有圈，并滚到中间；出局的变淡；每次受罚在名字下加一个点。
  - 底部动作区：这一刻的一到两个按钮，主按钮在右边，就在拇指下。游戏正文里不再放这些按钮。
  - 横屏：顶栏变矮，只写一种语言；左边有大画面（瓶子、转盘、骰子……）时，玩家条和按钮在右边一栏。
  - 小结（`GameTally.tsx`，结束页）：游戏开始以后（有人轮到、有轮次或受过罚），点返回或按手机的返回键，先出这局小结：
    谁喝得最多，每人受罚几次，三个按钮：继续这局（主按钮，误触返回不丢局）、再来一局、换个游戏。还没开始就直接返回。
    受罚盖章时按手机的返回键，等于点「继续」。
  - 加载（`GameLoading.tsx`）：游戏的文件还在下载时，先出游戏壳的样子：顶栏写好游戏名、能返回，玩家、舞台和按钮闪着占位；
    超过 2 秒加一句「网有点慢，马上就好」。不出现空白页。

## 组件

12 个组件已实现，接口在 `site/src/ui/types.ts`，一个组件一个文件。`site/ui-preview.html` 展示全部组件，
每个组件的预览在 `site/src/ui/preview/<Name>.tsx`；迁移旧页面时逐步换用它们。

| 组件 | 用途 | 现在对应的代码 |
| --- | --- | --- |
| Button | 所有「点了会发生事」的东西；一屏一个主按钮 | `site/src/ui/Button.tsx` |
| Tile | 网格里的一个游戏或工具，或首页顶上的大卡 | `site/src/ui/Tile.tsx` |
| Sheet | 从底下升起的弹层：菜单、玩家、设置、玩法、游戏介绍 | `site/src/ui/Sheet.tsx` |
| Tabs | 同一页里切换视图，或者胶囊形的单选 | `site/src/ui/Tabs.tsx` |
| Pill | 小标签（新、2 到 8 人），或能开关的筛选芯片 | `site/src/ui/Pill.tsx` |
| RosterChip | 今晚在场的一个人：头像加名字 | `site/src/ui/RosterChip.tsx` |
| OTPInput | 6 位邮箱验证码，或 4 位桌号 | `site/src/ui/OTPInput.tsx` |
| Toast | 自己出现、自己消失的一句话 | `site/src/ui/Toast.tsx` |
| EmptyState | 什么都还没有、或者没加载出来时说的话，带一个动作 | `site/src/ui/EmptyState.tsx` |
| Skeleton | 加载时的灰色占位，不让屏幕空着 | `site/src/ui/Skeleton.tsx` |
| GameHeader | 每个游戏顶上 56 高的栏：返回、名字、轮次或倒计时、声音、电视 | `site/src/ui/GameHeader.tsx` |
| PenaltyCard | 所有游戏共用的惩罚：喝一口、5 个俯卧撑、表演 | `site/src/ui/PenaltyCard.tsx` |

组件之间的约定：

- 玩家读到的字都从 props 进来，已经是读者的语言。双语标题传 `{ zh, en }` 加 `lang`。
  组件自带的几个字（关闭、返回、加载中）两种语言都写好，按 `lang` 选。
- 能按的东西都是真的 `<button>`，键盘和读屏软件才能用。最小 44。
- 对话框必须有名字：给标题，或者给 `label`。
- 弹层开着时，手机的返回键先关弹层，不离开页面（`router.ts` 的 `useBackCloses`）。页面地址本身就代表这个弹层的（游戏卡 `/g/<slug>`），传 `history={false}`。
- 出错时说人话，给一个能做的动作，不出现错误码。

## 已经落地的规则
