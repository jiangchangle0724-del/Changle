# 抓紧了 · 远景画

这里放每个世界的整张远景：`<世界>-far.webp`（`table-far.webp` 年夜饭桌，`van-far.webp` 温哥华）。
有就用，没有就全用程序画的剪影（`src/render/backdrop.ts`）。图会被铺满屏幕、压暗一点、跟着镜头横着挪一小段。

规矩：

- 原创：用 AI 生图时只写场景描述，不给任何别的游戏的截图或名字当参考；不要角色、不要字、不要水印。
- 尺寸：横图，长边 1536 左右；转成 WebP，质量 80，一张不超过 400 KB。
- 每张图在下表记一行：文件、怎么来的、提示词要点、日期。
