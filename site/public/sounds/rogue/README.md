# 流氓十三张的录音

- `hi.mp3`：陪酒牌的那声「hello」，一个女声，低低的、带气声（Steve 2026-11-21 要的「真人女声、妩媚一点」）。
  来源：freesound.org 的 sound 866789 “hello”，作者 annmariegerena，CC0 1.0（公有领域，不要求署名）。
  从原片 0.90 到 1.80 秒截的，单声道 44.1 kHz，峰值拉到 -3 dBFS，头尾各淡一下，MP3 -q:a 3。
  播放在 `src/games/rogueSounds.ts`（`sayHi`）；手机还没拿到这个文件时，那里合成的嗓音顶上。

换声音：把新的 MP3 放成同名文件就行，一秒上下、单声道、峰值别顶满。
